# Registration Form

A simple and responsive registration form developed using **HTML5**, **CSS3**, and **JavaScript**. The application validates user input on the client side by checking required fields and ensuring that the password and confirm password fields match before displaying a success message.

## 📌 Overview

This project demonstrates the fundamentals of front-end web development by creating an interactive registration form with basic form validation.

## ✨ Features

- Clean and responsive user interface
- User-friendly registration form
- Required field validation
- Password confirmation validation
- Success and error messages
- Simple and lightweight design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/ThanushaMuthuM/registration-form.git
```

2. Open the project folder.

3. Open `registrationform.html` in any modern web browser.

## 📖 Validation

- All fields are mandatory.
- Password and Confirm Password must match.
- Displays appropriate success and error messages.
